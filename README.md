# CI/CD Pipeline for a Student Attendance Management Portal

A minimal Student Attendance Management Portal (SAMP) delivered through a complete
DevOps toolchain: **Git/GitHub → Jenkins → Maven → Selenium → Docker → Ansible**.

> This project is delivered in 15 sequential tasks. Progress and the frozen
> technology stack are tracked in **[`docs/00-PROJECT-PLAN.md`](docs/00-PROJECT-PLAN.md)**.
> A full README (setup, build, run, deploy) is produced in Task 4.
